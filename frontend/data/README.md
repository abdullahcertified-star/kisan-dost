# Kisan Dost Datasets & Local Stores

This directory houses offline datasets, crop knowledge bases, and SQLite storage for Kisan Dost.

### Contents:
- **`kisan_dost.db`**: Local persistent SQLite database for farmer sessions, inquiries, and advisory history.
- **Reference tables**:
  - Pakistani crop calendars (Rabi / Kharif)
  - Recommended NPK fertilizer schedules
  - Provincial mandi market directories & AMIS data references
  - Subsidized scheme catalogs (e.g. Punjab Kisan Card)
